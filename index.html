Program overview

AI as an engineering collaborator

AI-Powered Inventor teaches students to build practical engineering harnesses that connect large language models to professional tools — CAD, circuit simulation, source control, fabrication, and hardware platforms — while keeping deterministic validation and human sign-off in the loop.

This is not a prompt-engineering course. It is a maker-to-engineer path where AI accelerates research, design, documentation, and iteration — and the engineer remains responsible for judgment, safety, and release.

Hybrid delivery

In class and online, same loop.

The instructor opens each phase. Students run the lab with their own LLM and portable agent packs — not a proprietary IDE. Web-directed activities extend the same gates into self-paced practice between sessions.

Open

State the goal, why the gate exists, and the done-when checklist (5–10 min).

Lab

Students follow exercise sheets, paste agent packs, produce design artifacts.

Demo or inject

Show a known-bad failure or a clean gate pass so the criterion is unmistakable.

Close

Collect one insight; point to the next exercise. Human review records Approve or Reject.

Audience: advanced makers, engineers, entrepreneurs, researchers, and technical professionals. Prerequisites: basic computer literacy; no prior AI experience required. Instructor: Brent A. Thorne.

Architecture

Agents may vary. Gates do not.

Every track shares one canonical loop. The LLM proposes; the harness orchestrates; tools execute; validators recompute without an LLM; a human signs off.
