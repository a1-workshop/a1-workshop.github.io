# A1 Workshop — GitHub Pages

Org root site for **A1 Workshop**: proposal landing for Humanmade administration plus public web-directed lab demos.

**Live:** [https://a1-workshop.github.io](https://a1-workshop.github.io)

## Contents

| Path | Role |
|------|------|
| `index.html` | Proposal landing (tracks, delivery, framework, outcomes) |
| `lab/gate-lite.html` | Interactive `Gate_Circuit_lite` demo |
| `styles.css` | Shared visual system |
| `lab/gate-lite.js` | Client-side validator + audit UI |
| `lab/fixtures/` | Known-good / known-bad design fixtures |

Curriculum SSOT remains in [`a1-inventor`](https://github.com/a1-workshop/a1-inventor). This site is the admin-facing packet and a taste of hybrid classroom / online delivery enhanced by web activities.
