How you learn

Self-paced. Same loop every phase.

Work through exercises with your own LLM and portable agent packs. Web activities use the same gates — no proprietary IDE required.

Orient

Read the goal, why the gate exists, and the done-when checklist.

Lab

Follow the exercise, run the agent pack, produce design artifacts.

Validate

Run the deterministic gate. Try a known-bad inject so the fail mode is clear.

Human review

Record Approve or Reject in the audit log — the agent never self-releases.

Architecture

Agents may vary. Gates do not.

The LLM proposes; the harness orchestrates; tools execute; validators recompute without an LLM; a human signs off.
